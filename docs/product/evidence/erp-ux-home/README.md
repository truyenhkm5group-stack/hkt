# ERP-UX — Hôm nay (trang chủ)

CSDL demo cục bộ (1.126 đơn), ADMIN tổ chức nhà. **Chưa phải ảnh production.** Khổ 1366 · 1440 · 390.
- TRƯỚC: mở đầu bằng ba thẻ doanh thu cỡ lớn; «Việc cần làm hôm nay» nằm dưới hai màn cuộn, số việc là một dòng chữ xám không bấm được.
- SAU: dải «Việc cần làm ngay» ngay dưới tiêu đề — mỗi ô một loại việc + số + bấm mở đúng danh sách đã lọc; «Bắt đầu từ việc này» (4 việc đầu hàng đợi) trước các thẻ tiền.
